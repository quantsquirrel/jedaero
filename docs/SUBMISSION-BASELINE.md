> 기능이 아무리 많아도 심사자는 한 이야기를 따라갈 수 없다.
>

## 2. 제출 전 중단 조건 — 하나라도 걸리면 제출보다 수정이 먼저

- [ ] PDF 첫 문장과 랜딩 히어로가 **다른 사용자·다른 문제**를 말한다
- [ ] 기능명세서에 있는데 화면에 없는 기능이 있다 (반대도 마찬가지)
- [ ] 팀원 아닌 계정·모바일에서 URL 이 안 열린다 (`smoke-url.sh` S2·S3 FAIL)
- [ ] 없는 주소·저장소 실패·세션 없음 중 하나라도 **빈 화면 또는 영문 오류**로 끝난다 (S5 FAIL)
- [ ] 화면·문서 어디든 «추천» «수익 보장» «최적 비중» «투자 판단 확정» 이 있다 (C8·C10)
- [ ] AI 응답에 배지가 빠진 곳이 있다 (C9, P0-14)

## 3. 왜 루트 URL 인가

`/demo` 를 제출하면 심사자는 랜딩을 건너뛰고 `/home` 의 «다음 편성까지 D-n» 부터 본다.
그 화면은 «무엇을 하는 서비스인가»를 말하지 않는다 — 그 설명은 전부 랜딩에서 끝내기로 했다(`app/page.tsx` 상단 주석).
루트로 들어오면 §0 문장 → 2,000만원 → 주말 한 번 → 포인트 20개 → 제대로 지수 → **[3분 심사 데모 시작]** 순서로
기획서 목차와 같은 순서로 읽힌다.
