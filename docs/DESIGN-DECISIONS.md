## 0. ★ 최우선 발견 — 심사 기간 5일이 전부 평일이다

```
2026-09-07 (월)  배포 URL 가용 시작 11:00
2026-09-08 (화)
2026-09-09 (수)
2026-09-10 (목)
2026-09-11 (금)  23:59 종료
```

**주말이 단 하루도 없다.** 이것이 설계 우선순위 전체를 바꾼다.

- 심사자는 기본 상태에서 **평일 화면만 본다**
- 주말 전용 기능(비중 조정, 리그, 수익률 공개, 주간 브리핑)은 요일 토글을 누르지 않으면 **전부 안 보인다**
- 즉 `/demo` 요일 토글은 편의 기능이 아니라 **결격 방지 장치**다.
  현재 상단에 작게 붙어 있는데, 놓치면 서비스의 절반이 평가에서 사라진다

**따라서:**

1. 평일 콘텐츠(브리핑룸)는 "평일이 심심하다"의 해결책이 아니라 **심사에서 실제로 평가받는 메인 화면**이다. 우선순위를 최상위로 올린다
2. 데모 진입 시 요일 토글을 눈에 띄게 배치하고, **"주말 모드로 전환하면 무엇을 볼 수 있는지" 명시**한다
3. 평일 화면 어딘가에 "이 서비스의 의사결정은 주말에 일어납니다 → 주말 모드로 보기" 유도가 상시 존재해야 한다

## 1. 기본 어휘: "실전"이 아니라 "워게임"

이 서비스의 법적 안전성은 전부 "명백히 모의다"(C5)에 걸려 있다.
UX 목표를 "실전 같다"로 잡으면 재미를 얻는 대신 그 선을 갉아먹는다.

**채택: 워게임 / 도상훈련.**

- 군에서 쓰는 정식 용어라 사용자에게 자연스럽다
- **단어 자체에 "이건 모의다"가 내장**되어 있다 — 워게임은 정의상 실전이 아니다
- 그런데도 진지하다. 승패가 있고 실력이 드러난다

### 파생 원칙: 군사 워딩은 "행위"에, 실명은 "대상"에

| 층위 | 표기 |
|---|---|
| 행위·구조·UI·공간 | 작전명, 예비대, 브리핑룸, 작전계획, 명령하달, 도상훈련 → **군사 워딩** |
| 자산·섹터·금융개념 | 반도체, 방산, 채권, 금, 수익률, 분산, 리밸런싱 → **실명 그대로** |

섹터·금융 용어에까지 가명을 붙이면 재미는 늘지만 학습 전이(transfer)가 죽는다.
전역 후 실제 증권 앱에서 같은 단어를 만나야 훈련이 의미를 갖는다.
**재미를 위해 학습 전이를 팔지 않는다.**

## 2. 예시 포트폴리오 워딩

### 결정: "안정형 / 공격형 / 수비형"은 쓰지 않는다

취향이 아니라 규제 문제.

- `CLAUDE.md` C10 및 "투자성향 라벨 금지"에 정면으로 걸린다
- **포트폴리오가 아니라 사람을 분류**하는 표현이다.
  "당신은 공격형입니다"는 투자자 성향 진단이고 미등록 유사투자자문 영역에 닿는다
- 작전명은 사람이 아니라 배치를 묘사하므로 이 문제를 피해간다

현재 코드의 `SAFE`도 사실상 "안정형"의 영문판이므로 교체 대상.

### 결정: 「대가」가 아니라 「작전 특징」 — 장점과 단점을 함께 쓴다

단점만 나열하면 방어적이고, 한 방향(분산)으로 몰아가는 인상을 준다.
**금융보안원을 과도하게 의식해 전략 다양성을 죽이지 않는다.**

각 예시 작전은 `작전명 + 성격 + 작전 특징(장단점)` 3종 세트.

**문체 규칙: 종결어미를 잘라낸 개조식.**
"측면이 열림." / "집중 돌파력은 낮아짐."
전략 게임의 브리핑 톤이 나오고, 조언조(~하세요)를 구조적으로 배제한다.

### 예시 작전 5종

**→ 포인트 배분까지 확정된 최종본은 §11-B 참조.** (버전이 갈리지 않도록 여기서는 원칙만 남긴다.)

- 각 작전은 `작전명 + 성격 + 작전 특징(장단점)` 3종 세트
- 문체는 개조식: `측면이 열림.` / `집중 돌파력은 낮아짐.`
- **균형 규칙:** 다섯 작전의 +/− 개수와 문장 무게를 비슷하게 유지한다.
  「돌파」의 −만 길면 그게 곧 "하지 마라"는 신호가 되어 추천이 된다.
  어느 것도 정답으로 보이면 안 된다.

## 3. 배분 UI ★ 대대적 개편 필요

### 현재 상태 진단 — 냉정하게 조악하다

배포본(`/portfolio`) 확인 결과:

- 「테마 6축 비중 (5%p 단위)」 아래 6개 항목이 나열되고 `−` `+` 버튼으로 퍼센트를 조정
- **자유도 시스템이 아예 구현되어 있지 않다**
- 시작 상태가 0%가 아니라 기존 배분값이 채워져 있다
- 퍼센트 조정 방식이 UX 관점에서 불편하다. 목표 비중에 도달하려면 버튼을 여러 번 눌러야 하고,
  전체 합을 사용자가 암산으로 추적해야 한다

### 결정: 자유도 3단계 — 단, 「선택지」가 아니라 「경로」로

| 단계 | 이름(안) | 조작 범위 | 대상 |
|---|---|---|---|
| 1 | 완전 데모 플랜 | 예시 작전 5종 중 선택 | 자유도 최하 · 기본 진입 |
| 2 | 포인트 편성 | 상위 6전선에 포인트 배분 (하위 테마는 지수추종) | 자유도 중간 |
| 3 | 완전 자유 편성 | 상위 배분 + 각 전선 내부 테마까지 조정 | 자유도 최상 |

**핵심 구조**
- 전체 병력을 나누는 것은 **상위 6전선**
- 각 전선 내부의 편성은 **하위 테마**
- **기본값 = 테마를 건드리지 않고 해당 전선의 지수를 그대로 추종**
- 자유도를 원하는 사용자만 아래층을 연다

### 결정: 화면 주역은 % 가 아니라 「포인트 20개」

5%p × 20 = 100%. 수학적으로 동일하지만 인지 부담이 전혀 다르다.

- "35%를 20%로 줄이고 나머지를…"는 **산수**
- "포인트 20개를 어디에 놓을까"는 **게임**
- 20대 초반이 RPG 스탯 분배로 이미 몸에 익힌 인터랙션
- 자동 재조정이 불필요해지는 이유도 자명해진다 — 포인트는 원래 유한하다

% 는 작은 글씨로 병기.

**포인트는 쪼개지지 않는 병력 단위로 다룬다.**
상위에서 「국내 주식」에 5포인트를 놓았다면, 3단계에서 그 5포인트를
`반도체 2 / 산업재 2 / 바이오·헬스케어 1` 로 다시 배치한다.
1포인트만 배치된 전선은 테마를 쪼갤 수 없다 — 이것이 집중의 물리적 한계를
자연스럽게 가르친다.

### 결정: 전 축 0에서 시작, 각 축 독립 조정, 합 100 이하

한 토글이 다른 토글을 자동으로 움직이는 재조정은
사용자가 자기 선택을 인지하지 못하게 만드는 안티패턴. 폐기.

### 결정: 미배치분을 「예비대」로 항상 표시한다

**"전부 0에서 시작"에는 부작용이 있고, 이 처리가 해독제다.**

Benartzi & Thaler의 근시안적 손실회피 연구의 결론은
*손실회피 투자자는 결국 주식 비중을 지나치게 낮게 가져간다* — 과소투자가 관찰된 실패 양상이다.

그런데 이 UI는: 기본값이 미투자 + 현상유지 편향 + 「그대로 두기」 퀘스트가 무행동에 보상.
셋이 겹치면 **서비스가 과소투자를 조용히 훈련시킨다.** 존재 이유와 정반대.

해법은 없애는 게 아니라 **보이게 만드는 것**:
- 미배치 잔여를 「예비대」로 하나의 축처럼 상시 표시
- "0%"가 아니라 "예비대 7포인트"라고 적히면 방치가 아니라 **선택**이 된다
- 특징 한 줄 병기: "잃지 않음. 다만 물가만큼 조용히 줄어듦."

> 「예비대」가 곧 현금 포지션이므로 별도의 "현금성" 축은 두지 않는다. 개념 중복.

## 4. 2층 구조 ★ 핵심 결정

### 배경: 전면 섹터화는 학습 콘텐츠를 부순다

상위 6축을 전부 주식 섹터로 바꾸면 상관계수가 높아 폭락장에서 같이 빠진다.

- 학습 카드 2단계 「분산이 무엇을 줄이는가」가 **사실상 거짓말**이 된다.
  6개로 나눴는데 다 같이 빠지면 사용자는 "분산은 사기"를 배운다
- 도상훈련의 −15% 이상 하락 구간에서 6축이 전부 빨간색이 되어
  리밸런싱을 가르칠 재료가 사라진다

### 결정: 층을 나눈다

```
상위 (필수)   상관관계가 낮은 6전선        ← 자산배분 교육 담당
하위 (선택)   각 전선 내부의 테마 배분      ← 재미·자유도 담당
```

**이 구조 자체가 학습 콘텐츠가 된다:**
> 테마를 나누는 것과 전선을 나누는 것은 다른 종류의 분산이다.
> 앞은 같은 전선을 넓히는 것이고, 뒤는 다른 전선을 여는 것이다.
> 폭락장에서는 앞의 분산이 거의 작동하지 않는다.

대부분의 개인투자자가 모르는 내용이고, 심사 관점에서 "이 팀은 금융을 안다"는 신호가 된다.

### 상위 6전선 재정비안

현재 6축은 상관관계 기준으로 문제가 있다:
`국내 대형주` + `국내 성장·테마` + `배당` = 사실상 전부 한국 주식. **6축 중 3축이 같은 것.**

**「배당」은 자산군이 아니라 스타일이다.** 배당주는 주식이고 국내에도 미국에도 있다.
상위에 둔 것은 범주 오류 — 하위로 내려가야 할 것이 위에 올라와 있다.
`국내 대형주 / 국내 성장·테마` 구분도 한국 주식 안의 구분이지 별개 시장이 아니다.

이 셋을 하위로 내리면 슬롯이 비고, 진짜 저상관 자산이 들어갈 수 있다.

| # | 전선 | 저상관 기여 |
|---|---|---|
| 1 | **국내 주식** | 기준 |
| 2 | **미국 주식** | 중간 (환율로 부분 분리) |
| 3 | **기타 해외 주식** | 중간 |
| 4 | **채권** | **높음** ★ |
| 5 | **금·원자재** | **높음** ★ |
| 6 | **리츠·인프라** | 중간 |
| — | **예비대** (미배치) | 현금 |

**→ 하위 테마 확정본은 §11-A 참조.** (버전이 갈리지 않도록 여기서는 상위 전선만 둔다.)

- 「리츠·인프라」에 *데이터센터·전력망*이 들어간다. 2026년 AI 인프라·전력이
  신규 주도 테마로 부상 중이라 시의성이 좋고, 20대에게 설명이 필요 없는 단어다
- 하락 구간에서 4·5번이 실제로 다르게 움직여야 리밸런싱 교육이 성립한다.
  **이 두 전선이 도상훈련 데이터의 핵심 검증 포인트**

### 결정: ETF(지수 바스켓) 단위 — 단, 실존 상품명은 쓰지 않는다

- 개별 종목명 노출은 C10(종목 리딩·추천 금지) 직행
- ETF = 바스켓이라 구조적으로 안전하고, 전역 후 실제 접근 가능한 형태라 학습 전이가 된다

**운용사 브랜드가 붙은 실제 상품명은 금지.**
§11에서 실제 데이터를 쓰기로 했으므로 "가격은 가짜인데 상품은 진짜"인 모순은 사라졌다.
그러나 **금지 이유는 그대로 남는다 — C10.**
같은 섹터에 여러 운용사 상품이 있는데 하나를 골라 표시하는 것 자체가 특정 상품 지목이 된다.

```
✗  KODEX 반도체          ← 특정 운용사 상품 지목
✓  국내 반도체 지수       ← 지수·바스켓 수준
```

학습 카드에는 복수형으로: *"이런 지수를 따라가는 ETF가 여러 운용사에서 나와 있습니다.
전역 후 증권 앱에서 '섹터 ETF'로 검색하면 나옵니다."*

### D-5 현실: 하위 UI는 두 전선에만 먼저 연다

§11에서 API 연동으로 전환하면서 **데이터 확보 비용은 더 이상 이유가 아니다**
(전 섹터를 균등하게 받아온다). 남는 것은 **UI 복잡도**다.

**국내 주식·미국 주식 두 전선에만 하위 조정 UI를 먼저 열고, 나머지는 기본값 고정.**
재미는 전부 주식 테마에 있다. 아무도 "회사채를 국채와 나눠 담고 싶다"고 하지 않는다.
데이터는 전부 들어와 있으므로 나머지 전선의 UI는 언제든 열 수 있고,
그 확장성 자체가 발표 자료 소재가 된다.

### 특정 테마를 특별 취급하지 않는다

**모든 주식 데이터에 동일한 관심을 둔다.**
방산은 산업재(조선·기계·방산) 안의 한 항목일 뿐이며, 별도 축이나 대표 테마로 두지 않는다.

- 특정 테마를 부각하는 것 자체가 §7의 금지 항목("특정 테마를 지금 뜨는 것으로 부각")에 해당
- "군인에게 방산주를 권하는 서비스"로 읽힐 여지도 만들지 않는다
- API로 실제 데이터를 받으면 가용성 제약이 없으므로 전 섹터를 고르게 다룰 수 있다

## 5. 평일 설계 ★ AI 개입의 최대 지점

§0에서 확인했듯 **심사 기간 전체가 평일이다.** 여기가 실제 평가 화면이다.

### 브리핑룸 — 평일 상설 공간

**목표: 평일에 이 웹에 들어오는 것만으로 오늘 시장이 어떻게 움직였는지
깔끔한 인터페이스로 한눈에 파악된다.**

구성 요소:

1. **주요 지수 변동 종합** — 오늘/이번 주 시장 전반
2. **내 편성 중심 시황** — 내가 고른 전선·테마의 움직임을 중심으로 재구성.
   같은 시장 정보라도 사용자마다 다른 순서로 보인다
3. **AI 판단 분석** — 사용자의 편성과 작전계획에 대해 AI가 분석
4. **전우 대비 내 편성의 특징** — 다른 사용자 대비 내 포트폴리오가
   어떤 부분이 특징적인지 여러 관점에서 서술

이것이 **AI가 개입해야 할 가장 큰 부분**이다.
정보를 종합해 가독성 좋은 문장으로 요약하는 것 — 그것이 AI의 역할.

### 결정: 수익률 마스킹을 폐지하지 않고 「지표 교체」로 바꾼다

**지적은 타당했다** — "어차피 폰으로 시황 보는데 무슨 마스킹이냐".
정보 차단으로서의 마스킹은 이미 실패한 전제 위에 있고, 실패한 통제는 UX만 나쁘게 만든다.

**그러나 폐지하면 서비스의 핵심 논거를 버린다.**
Benartzi & Thaler의 결론은 "정보를 차단하라"가 아니라
**"평가 주기가 투자 기간과 어긋나면 판단이 망가진다"**이다.

갈리는 두 행동:
- **시황을 보는 것** — 막을 수도, 막을 필요도 없다
- **내 손익 숫자를 반복해서 보는 것** — 이것이 판단을 망가뜨린다

현재 마스킹은 둘을 뭉뚱그려 잠근다.

```
평일   누적 수익률 (시작 이후)      — 천천히 움직임, 감정 반응 낮음
주말   이번 주 변동 + 전선별 등락    — 빠르게 움직임, 의사결정용
```

1. **아무것도 잠기지 않는다.** 평일에도 항상 진실한 자기 숫자를 본다
2. **MLA 이론에 오히려 더 충실하다.** 요지는 "보지 마라"가 아니라 "기간에 맞는 지표를 보라"
3. **우회 불가능이 아니라 우회 불필요가 된다**

학습 카드 3단계 제목도 「왜 매일 보면 안 되는가」(훈계조) →
**「매일 보는 숫자와 주 단위로 보는 숫자는 다르다」**(사실 서술)로 교체.

> **비중 조정 주말 1회 규율은 절대 건드리지 않는다.**
> 마스킹과 조정 잠금은 별개 기능이다.

### 결정: 「작전계획 → 명령하달」 2단 구조 ★

평일에 읽을거리만 얹으면 소비되고 끝난다. **평일에도 "결정"이 있어야** 루프가 돈다.
그런데 주 1회 조정 규율은 깨면 안 된다.

**평일에는 하고 싶은 조정을 미리 적어둘 수 있다. 실행되지 않고 주말 창에 초안으로 대기한다.**

1. 평일에 진짜 결정이 생긴다 — 읽고 끝이 아니라 자기 판단을 남긴다
2. 규율은 그대로 — 실행은 여전히 주말 1회
3. **화요일의 충동과 토요일의 판단 사이 간극이 데이터로 남는다.**
   화요일에 "반도체 다 빼야지"라고 적었다가 토요일에 안 바꾸는 경험 —
   그게 이 서비스가 가르치려는 것 전부다.
   지금은 말로 설명하는데, 이 방식은 **본인 기록으로 직접 보게** 만든다
4. **AI 개입의 최적 지점.** 주말에 "화요일엔 이렇게 적으셨고 지금은 다르게 하셨습니다"
   — 사실 한 문장 + 질문 하나. 조언이 아니라 사실 서술이라 가이드라인을 지키면서
   AI가 가장 인상적으로 쓰이는 순간이 된다
5. 군사교리 흐름 그대로: **상황 판단 → 작전 계획 → 명령 하달**

브리핑을 바탕으로 사용자가 **스스로 근거를 세우고 판단을 내리게** 만드는 것이 목적.
그 판단 과정을 기록·분석해 읽기 쉬운 문장으로 요약하는 것이 AI의 큰 역할.

### 카운트다운

평일 상단에 **「작전 회의까지 D-2」** + "이번 주 정찰 보고 3건 도착".

푸시 대신 **기다림을 설계**한다. 푸시는 서비스가 사용자를 부르는 것이고,
이건 사용자가 스스로 기다리게 만드는 것. **심사자가 평일에 접속해도 즉시 보인다.**

## 6. 브리핑룸 부가 기능

### 도상훈련 (과거 시나리오 스트레스 테스트) ★

> **"2020년 3월. 시장이 한 달 만에 30% 빠졌습니다. 지금 편성이라면?"**
> → 현재 배치를 과거 폭락 구간에 그대로 넣고 결과를 보여준다.

- **예측이 아니다.** 과거 데이터에 현재 배치를 적용할 뿐이라 조언·전망 금지 원칙을 지킨다
- **손실을 몸으로 배운다.** "최대낙폭 −23%"보다 "2,020만원이 1,555만원이 됨"이 백 배 강하다
- **도상훈련은 실제 군사 용어다.** 비유가 아니라 하는 일이 같다
- 「돌파」와 「종심 방어」를 같은 시나리오에 넣어 나란히 보여주면
  **작전 특징 문구가 숫자로 증명된다**
- 심사자 시연에 완벽하다. 버튼 하나로 극적인 화면이 나온다
- **신규 사용자의 첫 주 공백을 메운다** — 이력이 없어도 즉시 가능

시나리오 3~4개: 2020 코로나 급락 / 2022 금리 인상기 / 2008 금융위기.

### 관측 훈련 — 예측 퀴즈가 아니다

```
✗  "다음 주 반도체가 오를까요?"      → 시장 예측을 훈련시킴. 최악
✓  "지난주 가장 크게 움직인 전선은?"  → 관찰력을 훈련시킴
```

예측 퀴즈는 절대 넣지 않는다. 재미있어 보이지만
**"시장은 맞히는 것"이라는 정반대 교훈**을 심고, 맞히면 붙는 자신감이 과잉거래로 간다.

### 전우들의 편성 — 순서가 성격을 뒤집는다

1. **자기 작전계획을 확정한 뒤에만 열린다.**
   결정 전에 보면 앵커링(따라하기), 결정 후에 보면 성찰.
   **순서 하나가 기능의 성격을 정반대로 만든다**
2. **인기가 아니라 분산도를 보여준다.**
   "68%가 반도체를 담았습니다"는 추종 유발 문구.
   **"이번 주 편성은 크게 갈렸습니다"** / **"당신은 소수파입니다"**가 맞는 표현
3. **수익률을 절대 붙이지 않는다.** 기존 원칙(그룹 응답에 수익률 필드 없음) 승계
4. 기존 옵트인·상호주의·k-익명성(n<20 상위 코호트 합산) 규칙 그대로 승계

### 프레이밍: "기회"가 아니라 "지형" — 퍼센트로만 표시

```
✗  "반도체가 이번 주 강세입니다"              → 기회로 읽힘 → 추격
✓  "이번 주 지형: 반도체 +3.2% / 채권 −0.4%"   → 조건으로 읽힘
```

지형과 기상은 **좇는 것이 아니라 고려하는 것**이다. 같은 숫자인데 동사가 달라진다.
브리핑 전체를 "이번 주 지형" 톤으로 통일한다.

### 열람 등급

학습 카드를 끝낼 때마다 브리핑 깊이가 열린다. **3급 → 2급 → 1급.**
군 문서 등급 그대로라 설명이 필요 없고, 학습 카드를 읽을 이유가 생긴다.

**단, 기능은 절대 잠그지 않는다.** 잠그는 것은 *심화 해설*뿐.
접근권 제한은 이 프로젝트의 배려 원칙(휴가·당직 병사의 접근권)과 충돌한다.

## 7. 게임화 안전 점검 — 전체 구축 후 일괄 수행

Robinhood는 색종이 애니메이션·복권식 UI로 거래를 게임화했다가 과잉거래 유도로
규제당국에 750만 달러를 지불했고, SEC는 인터페이스 설계 자체를 규율하는 규칙을 제안했다.
주최가 금융보안원인 이상 심사위원 중 누군가는 반드시 이 각도로 본다.

**단, 기능 구축 단계에서 항목마다 일일이 검열하지 않는다.**
고려할 것이 너무 많아져 아무것도 못 만들게 된다.
**전체 시스템을 완성한 뒤 일괄 점검 라운드를 돈다.**
완성된 상태에서 보면 무엇이 위험한지 직관적으로 드러난다.

점검 시 사용할 판별 기준:

> **행동의 빈도를 늘리는 게임화는 금지. 행동의 질을 높이는 게임화만 허용.**

| 허용 | 금지 |
|---|---|
| 작전명·테마·포인트 배분의 손맛 | 조정 횟수를 늘리는 모든 것 |
| 배지·XP·브리핑의 서사 | 수익률 순위 1등 표창 |
| 「그대로 두기」에 보상 | 잦은 변경에 보상 |
| 장단점을 함께 적은 작전 카드 | 특정 테마를 "지금 뜨는" 것으로 부각 |

**이 표 자체를 발표 자료에 넣는다.** "게임화하되 Robinhood와 반대 방향으로 갔다"는
서사는 금융보안원 심사에서 정확히 작동한다.

## 11. ★ 데이터 출처 — 실제 데이터 + 일별 갱신 API

### C6의 실제 근거를 확인했다 — 규제가 아니다

`SPEC.md` 14행 원문:

> 병사는 평일 18:00~21:00, 휴일 08:30~21:00에만 휴대전화를 쓸 수 있고,
> **국내 정규장(09:00~15:30)과 1분도 겹치지 않는다.**
> 장중에 시세를 볼 수 없으니 패닉 매매가 구조적으로 불가능하다.

**법령이 아니라 사용자 접근 시간 분석이다.** 그리고 이것이 이 서비스의 창립 통찰이다.
C6는 "규제가 금지해서"가 아니라 **"실시간을 볼 수 있는 사람이 아무도 없어서"** 생긴 조항.

### 그러나 실시간은 다른 이유로 막힌다 — 유료 라이선스

실시간 시세는 **코스콤(KRX)과 정보이용계약 없이는 API로 받아 자사 앱 화면에 표시하는 것 자체가 불가**하다.
계약 없이 쓰면 서비스 제한 대상. 공모전 출품작이 유료 시세 계약을 맺는 것은 비현실적이다.

**실시간은 근거가 불확실해서가 아니라 실제로 막혀 있어서 못 쓴다.**

### 결정: 일별 종가 API 채택 (실시간 아님)

| 소스 | 비용 | 지연 | 비고 |
|---|---|---|---|
| 공공데이터포털 금융위원회_주식시세정보 | **무료** | D+1 (익영업일 13시 이후) | 상업 제한 없음 |
| 금융위원회_지수시세정보 | **무료** | D+1 | 지수 전용 |
| KRX OPEN API | 무료 | D+0 (장 마감 후) | 비상업 제한, 일 10,000회 |

### 실시간을 포기해도 손해가 아닌 세 가지 이유

1. **볼 사람이 없다.** 병사 폰 사용 시간(평일 18:00~21:00)과 정규장(09:00~15:30)이 안 겹친다.
   실시간 틱을 붙여도 아무도 못 본다. 계약료를 내고 아무도 못 보는 기능을 만드는 셈
2. **병사가 폰을 켜는 18시는 이미 장 마감 후다.** 그 시점에 필요한 건 실시간이 아니라
   **"오늘 종가"**다. 일별 갱신이면 정확히 충족된다
3. **실시간은 서비스 철학과 정면 충돌한다.** "장중에 보지 않는 훈련"이 핵심인데
   실시간 시세를 띄우면 자기부정이다. 심사에서 바로 지적당한다

**생동감은 실시간이 아니라 "매일 숫자가 바뀐다"에서 온다.** 일별 갱신으로 충분하다.

### 외부 장애 리스크 처리

C6의 나머지 우려("심사 기간 외부 장애 차단")는 **받아서 저장 + 실패 시 마지막 저장분 사용**으로 해소된다.
외부 API가 죽어도 서비스가 죽는 게 아니라 숫자가 하루 안 바뀔 뿐이다.

### 연쇄 결정: 블라인드 리플레이 폐기

라이브 데이터를 쓰면 과거를 재생할 이유가 없다. **오늘이 진짜 오늘이다.**
대신 역할을 나눈다:

```
본 시간축   실제 현재 · 매일 갱신         → 생동감
도상훈련    실제 과거 극단 구간 · 고정     → 하락 교육
```

**−15% 하락 학습은 도상훈련이 담당한다.** 사용자 본인 곡선에 하락이 없어도
2020·2022 구간에 자기 편성을 넣어보면 된다. 오히려 더 강력하다 —
지금 고른 배치가 실제 폭락장에서 어떻게 되는지 즉시 보게 되므로.

> **P0-11(가격 시드에 −15% 구간 필수)의 검증 대상이 시드 → 도상훈련 데이터로 이동한다.**
> 09-04 미팅에서 짚을 것.

### 데이터 범위 — 전 섹터 균등

특정 섹터를 특별 취급하지 않는다. 모든 주식 데이터에 동일한 관심.
API로 받으면 데이터 가용성 제약이 사라지므로 전 섹터를 고르게 다룰 수 있다.

**표시는 일반명 유지** (`국내 반도체 지수`). 운용사 브랜드 노출은 특정 상품 지목이 되어 C10 인접.
학습 카드에서 복수형으로 안내: *"이런 지수를 따라가는 ETF가 여러 운용사에서 나와 있습니다."*

### 확인 필요

- **KRX OPEN API 비상업 용도 제한** — 공모전 출품작·교육 목적이므로 해당되나,
  발표 자료·서비스 하단에 데이터 출처 명시할 것
- 공공데이터포털(D+1)과 KRX(D+0) 중 어느 쪽을 주 소스로 할지.
  D+1이어도 "매일 숫자가 바뀐다"는 동일하며, 즉시성 압박이 없어 철학에 더 맞는 면도 있다

- **방산은 산업재 안의 한 항목.** 특별 취급하지 않는다

## 11-B. 예시 작전 5종 — 확정

포인트 20개 기준 배분. 표기 순서는 `국내 · 미국 · 기타해외 · 채권 · 금 · 리츠`.

### 연합작전
`4 · 4 · 3 · 4 · 3 · 2`
전 전선에 고르게 배치.
```
+ 어느 전선이 무너져도 전체는 유지됨.
+ 변동성 낮음. 판단 부담 적음.
− 어떤 해에도 선두는 어려움.
− 급등장에서 상대적 박탈감 큼.
```

### 돌파
`7 · 8 · 3 · 0 · 1 · 1`
주식에 화력 집중. 방어 자산 최소.
```
+ 상승장 속도 최대.
+ 구조 단순. 판단 빠름.
− 측면이 열림. 하락장 방어 병력 없음.
− 변동성 큼. 흔들림을 오래 견뎌야 함.
```

### 종심 방어
`2 · 3 · 1 · 9 · 4 · 1`
채권·금으로 방어선을 겹쳐 깖.
```
+ 낙폭 얕음. 흔들림 적음.
+ 하락장에서 재편성 여력 남음.
− 상승장 수익 제한적.
− 물가 상승분을 못 따라갈 수 있음.
```

### 거점 확보
`2 · 11 · 1 · 4 · 1 · 1`
최대 시장에 거점. 나머지는 얇게.
```
+ 최대 시장에 거점. 유동성 풍부.
+ 환율 상승 시 이중 수혜.
− 환율 하락 시 이중 타격.
− 미국 시장 정체 시 동반 정체.
```

### 정찰 침투
`2 · 3 · 2 · 3 · 2 · 1` · **예비대 7**
넓고 얕게 배치. 실탄 보유.
```
+ 실탄 보유. 기회 시 즉시 투입 가능.
+ 개별 실패의 타격 작음.
− 무엇이 올라도 체감 작음.
− 예비대는 물가에 잠식됨.
```

> 「정찰 침투」만 20포인트를 다 쓰지 않는다.
> **예비대 개념을 예시로 직접 보여주는 장치**다.

> **균형 규칙:** 다섯 작전의 +/− 개수와 문장 무게를 비슷하게 유지한다.
> 어느 것도 정답으로 보이면 안 된다.
