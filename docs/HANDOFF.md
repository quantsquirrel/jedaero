## 5. 환경 함정 — 반드시 알고 시작할 것

### 세션은 프로젝트 폴더에서 시작할 것

```bash
cd ~/projects/jedaero && claude
```

홈 디렉토리에서 시작하면 **`CLAUDE.md`가 자동 로딩되지 않는다.**
그 파일에 절대 금지 C1~C11(카메라·GPS·현금성 보상·부대정보 등)이 있으므로
못 읽은 채로 작업하면 위험하다. 이미 다른 곳에서 시작했다면 `/add-dir ~/projects/jedaero`.

### API 키 위치

```
.env          실제 값. gitignore 대상. KRX_API_KEY · DATA_GO_KR_API_KEY 들어 있음
.env.example  자리만 표시. 추적되는 파일이므로 여기에 실제 값을 절대 넣지 말 것
```

`.gitignore`에 `!.env.example` 예외가 있어 이 파일은 커밋된다.

### `.env`가 없다

```
DATABASE_URL 없음 → npm run build 실패 (Failed to collect page data for /home)
                  → bash scripts/verify.sh 의 DB 항목 전부 FAIL
```

**코드 문제가 아니다.** DB 없이 도는 검증 항목만 신뢰할 것.

### 로컬 확인 방법

```bash
DATABASE_URL="postgresql://u:p@localhost/db" npx next dev --port 3111
```

- `/` (랜딩), `/onboarding` 은 DB를 안 써서 **더미 URL로도 200**
- `/home`, `/portfolio` 등은 **실제 DB 세션이 필요해 로컬 확인 불가**
- 커밋 메시지에 무엇을 검증했고 무엇을 못 했는지 정직하게 적을 것

### git push가 그냥은 실패한다

VS Code git 소켓 때문에 인증이 깨진다. 이렇게 해야 한다:

```bash
git -c credential.helper='!gh auth git-credential' push
```
