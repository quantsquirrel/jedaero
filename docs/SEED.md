## 1. 예시 포트폴리오 4종

`allocations.template_id`에 저장. **합계는 각각 정확히 100.**

| id | 표시 이름 | KR_LARGE | KR_THEME | US_INDEX | BOND_CASH | GOLD_COMM | DIVIDEND |
|---|---|---|---|---|---|---|---|
| `GLOBAL` | 전세계 지수 추종 | 20 | 0 | 50 | 20 | 10 | 0 |
| `DOMESTIC` | 국내 중심 | 40 | 20 | 0 | 20 | 0 | 20 |
| `SAFE` | 안전 우선 | 0 | 0 | 20 | 50 | 10 | 20 |
| `FOCUS` | **집중** | 20 | 60 | 20 | 0 | 0 | 0 |

각 카드에 함께 표시할 것:

- 시드 구간 기준 **누적수익률**
- 시드 구간 기준 **최대낙폭(MDD)** ← `FOCUS`에서 특히 크게
- 한 줄 설명 (아래)

| id | 한 줄 설명 |
|---|---|
| `GLOBAL` | 전 세계 주가지수를 그대로 따라갑니다. 가장 흔한 시작점입니다. |
| `DOMESTIC` | 국내 기업 위주로 담습니다. 아는 회사부터 보고 싶을 때. |
| `SAFE` | 절반을 채권·현금에 둡니다. 값이 덜 흔들립니다. |
| `FOCUS` | 특정 테마에 몰아넣습니다. 오를 때 크게 오르고 빠질 때 크게 빠집니다. |

> **금지**: "추천", "안정형", "공격형", "위험중립형", "당신에게 맞는".
> **허용**: "예시", "템플릿", 위 전략 이름 그대로.

## 3. 가격 시드 요구사항 ★

`prices` 테이블. **최근 12개월치 일별 종가** (영업일만, 주말·공휴일 행 없음).

### 필수 조건

| # | 조건 | 이유 |
|---|---|---|
| 1 | **중간에 -15% 이상 하락 구간 포함** | 없으면 「매달 모았다면」에서 두 곡선이 겹쳐 교육 효과가 0 |
| 2 | 하락 후 **부분 회복** | 적립식이 유리해지는 구간을 만들기 위해 |
| 3 | 축별로 변동성이 다름 | `BOND_CASH` 낮음 → `KR_THEME` 높음 |
| 4 | 종가는 **정수(원)** | 부동소수 금지 |
| 5 | 결정론적 생성 (시드 고정) | 재실행 시 같은 데이터 |

### 권장 생성 방식

```
기하 브라운 운동(GBM) + 지정 구간 드로다운 주입
축별 연간 변동성 목표:
  BOND_CASH   3%
  DIVIDEND   12%
  KR_LARGE   18%
  US_INDEX   18%
  GOLD_COMM  20%
  KR_THEME   32%
드로다운: 전체 구간의 40~55% 지점에서 시작해 6주간 하락, 이후 10주간 부분 회복
하락 폭은 축 변동성에 비례 (KR_THEME 약 -30%, BOND_CASH 약 -3%)
```

생성 스크립트는 `scripts/` 에 두고, 결과를 `db/seed/prices.ts` 또는 SQL로 커밋한다.
**런타임에 생성하지 말 것.** 매 요청마다 값이 달라지면 안 된다.

## 4. 위클리 퀘스트 5종

`quests` 테이블.

| code | title | description | xp | badge |
|---|---|---|---|---|
| `RECORD_3` | 지출 3건 기록 | 이번 주에 쓴 돈 3건을 기록해 보세요 | 30 | — |
| `CONFIRM_AI` | 분류 5건 확인 | AI가 제안한 분류 5건을 확인하고 확정하세요 | 20 | — |
| `LEARN_1` | 학습 카드 1개 | 학습 카드 하나를 끝까지 읽으세요 | 20 | — |
| `REVIEW_1` | 주말 회고 | 이번 주를 한 줄로 돌아보세요 | 30 | `REFLECT` |
| `HOLD` | 그대로 두기 | 이번 주 비중을 바꾸지 않았습니다 | 20 | `PATIENT` |

> `HOLD`는 **아무것도 하지 않은 것에 대한 보상**이다. 이걸 빼면 "가만히 있기"가 미참여로 취급된다.

## 8. 데모 시드 데이터

`/demo` 진입 시 주입.

| 항목 | 규모 |
|---|---|
| 지출 이력 | 3개월치, A/B/C가 골고루 섞이게 |
| 비중 변경 이력 | 12주치. **조정하지 않은 주 2주 포함** |
| 더미 사용자 | 200명 (리그·성향 분석 분포용) |
| 예산 봉투 | 확정(잠금)된 이번 달 + 미확정 다음 달 |
| 퀘스트 | 5종 중 2종 완료 상태 |

더미 사용자 닉네임은 **실명처럼 보이지 않게** 생성할 것 (예: `해뜰날`, `강철비`, `초코우유`).
