## 1. MVP 구현 범위

제출 URL에서 동작하는 범위다.

- 랜딩 `/` — 한 줄 정의, 시드 2,000만원, 「3분 심사 데모 시작」 / 「시작하기」
- 익명 세션 — 이메일 가입 없음. `/demo`가 사용자를 만들고 쿠키를 붙인다
- 데모 요일 토글 — 심사 주간은 전부 평일. 주말 화면을 보려면 토글이 필요하다
- 온보딩 — 별명·계급·군종·날짜·거리 구간 → 예시 작전 5종
- 홈 — 다음 편성까지 D-n, 오늘의 지형(전선 등락). 평일=누적 수익률 / 주말=평가액+이번 주 변동+제대로 지수
- 포트폴리오 — 포인트 20, 예비대, 하위 테마(국내·미국 주식, 2포인트 이상), 목표 vs 현재 갭. 주말에만 확정
- 평일 명령하달 초안 — 체결되지 않는 메모. 안 적어도 된다
- 제대로 지수 — 3축 막대. 우리 그룹 / 같은 군종 / 같은 계급. 등수 없음. 목록은 가입순
- 학습 — 카드 5장, 등락표, 도상훈련 3장, 한 줄 회고
- 그룹 — 초대코드, 정원 30, 부대 식별 이름 차단
- 성향 분석 — 옵트인. 주말에만 비교
- 나의 투자 원칙 `/principles` — 사실 문장, 공표 기관 배분 비교, 이미지 저장, 「왜 다른지」 AI
- AI 출력 가드·숫자 가드·분당/일 한도·관리자 킬스위치

**이 범위에 없음 (화면도 없음).** 가계부, 퀘스트, 경험치, 개별 종목 주문서, 비중 슬라이더, 두 곡선 합산 「총 자산」, 실시간 시세, 로그인, 카메라·위치 API.

| 주간 브리핑 (AI-4) | 주말만 내 비중 가중 + 요약 + 질문 3개. 평일은 등락표만 | `/learn` `/home` | 동작 |

## 3. 사용자 이용 흐름

배포 URL **https://jedaero-seven.vercel.app** 접속 후.

```
랜딩 (/)
  ├─ [3분 심사 데모 시작] → /demo → 쿠키 세션 → /home
  └─ [시작하기] → /onboarding → 예시 작전 → /home

/home (상단 「3분 심사용 동선」이 항상 열려 있음)
  1 시장 읽기     /home#market          평일
  2 AI 코치       /home#ai-coach        평일
  3 주말 편성     /portfolio            상단 토글을 주말로
  4 제대로 지수   /league               상단 토글을 주말로
  5 도상훈련      /learn#drill          요일 무관
  6 나의 투자 원칙 /principles          요일 무관. 전역 후에도 남는 기록
```

평일 기본 화면에서는 편성 버튼이 잠긴다. 「주말에만 조정할 수 있습니다」가 보인다. 심사 주간은 평일뿐이므로, **3·4를 보려면 반드시 상단 토글을 주말로 바꾼다.**

## 4. AI 및 데이터 처리 방식

### AI가 하는 역할

규칙이 만든 숫자(등락, 갭, 유지 주수, 배분)를 받아 **사실 문장과 질문**을 만든다. 비중을 바꾸거나 종목을 고르거나 주말 확정을 대신하지 않는다.

모델: Anthropic Claude. 키가 없거나 가드에 걸리면 **같은 자리**에 규칙 문장이 뜬다. 화면이 비지 않는다.

### 입력 · 출력

| 구분 | 내용 |
|---|---|
| AI에 넣는 것 | 편성, 유지 기간, 주간 등락(주말만 내 비중), 한 줄 회고, 공표 기관 배분 |
| AI가 돌려주는 것 | 사실 서술 + 열린 질문. 생성형 AI 배지 |
| AI에 넣지 않는 것 | 실시간 시세, 뉴스 본문, 소속 부대, 평일의 내 손익 |

출력에 조언 어미·전망·입력에 없던 숫자가 있으면 폐기한다 (`output-guard`, `number-guard`).

### 개인정보 · 민감정보

- 실명·주소·주민등록번호·계좌·소속 부대를 **받지 않는다.** 스키마에 컬럼이 없다.
- 거리 구간은 `NEAR|MID|FAR|ISLAND` 네 값이다. 주소 원문을 저장하지 않는다.
- 회고 원문은 응답을 만든 뒤 버린다.
- 그룹명에 사단·대대 등 부대 식별이 있으면 저장 전에 차단한다.
- 호출 한도: 분당 5회, 일 50회.

### 저장 / 요청 때 계산 / 폐기

| 처리 | 대상 |
|---|---|
| 저장 | 별명·계급·군종·날짜·거리 구간, 주말 편성, 평일 초안, 그룹 소속, 분석 동의, 시세 시드 |
| 요청 때 계산 | 수익률, 평가액, 보유수량, 제대로 지수 |
| 폐기 | 한 줄 회고 본문 |

크론·백그라운드 작업 없음. 로그인 라이브러리 없음.

## 5. MVP 검증 방법

### 심사자가 할 일

1. 시크릿 창 또는 본인 휴대폰에서 **https://jedaero-seven.vercel.app** 을 연다. `/demo`를 제출 URL로 쓰지 않는다.
2. 「3분 심사 데모 시작」을 누른다. **계정은 필요 없다.**
3. 상단 동선 1→6을 따른다. 3·4 전에 **주말 토글**을 켠다.
4. 아래 표의 예상 결과가 맞으면 해당 기능이 동작하는 것이다.

테스트 계정: 없음. `/demo`가 익명 사용자를 만든다. 다시 처음부터 보려면 `/demo?new=1`.

### 실행 환경

- 모바일 Chrome / Safari, 데스크톱 Chrome.
- 가입·카메라·위치 권한 없음.
- 배포 보호(Vercel Deployment Protection) 꺼짐. 팀원 아닌 기기로 열어야 한다.
- 가용 시간: **2026-09-07 11:00 ~ 09-11 23:59** (미접근 시 결격).

### MVP 단계의 제한

- 시세는 교육용 합성 데이터다. 실제 시장과 맞물리지 않는다.
- 쿠키를 지우거나 기기를 바꾸면 같은 편성 이력으로 이어지지 않는다. 계정 복구 없음.
- 관리자 `/admin`은 심사 3분 동선에 넣지 않았다.
- 생성형 AI 키가 꺼져 있어도 핵심 숫자·폴백 문장은 동작한다.
